📦 INSTALLATION
───────────────────────────────────────────────────────────────
1. Open terminal/command prompt
2. Navigate to project folder:
   cd noe-portfolio

3. Install dependencies:
   npm install

4. Start development server:
   npm run dev

5. Open browser: http://localhost:5173

  npm install -g vercel
  vercel

Deploy to Netlify:
  npm run build
  (Upload 'dist' folder to Netlify)

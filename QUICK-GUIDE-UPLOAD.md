# 🚀 QUICK GUIDE - Upload Foto Profil

## ⚡ **3 LANGKAH CEPAT**

### **1️⃣ SIMPAN FOTO**
```
Klik kanan foto di chat → Save as → profile.jpg → Desktop
```

### **2️⃣ COPY KE PROJECT**
```
Copy dari Desktop → Paste ke:
D:\Personal Branding\noe-portfolio\public\images\
```

### **3️⃣ TEST**
```bash
npm run dev
```
Buka: `http://localhost:5173`

---

## 📸 **Foto yang Anda Upload:**

Foto profil dengan:
- ✅ Background hijau
- ✅ Pose natural berdiri
- ✅ Pakaian: Cardigan coklat + kaos biru

**Akan muncul di Hero section sebagai:**
- 🔵 Bentuk: Lingkaran (circular)
- 🔴 Efek: Glow maroon (merah)
- ⚡ Animasi: Pulse + hover zoom
- 📍 Posisi: Kiri (di samping deskripsi)

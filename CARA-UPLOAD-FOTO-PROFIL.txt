📋 LANGKAH 1: SIMPAN FOTO DARI CHAT

1. Scroll ke atas di chat ini
2. Cari foto profil Anda (background hijau, pose berdiri)
3. Klik kanan pada foto
4. Pilih "Save image as..." atau "Simpan gambar sebagai..."
5. Ketik nama file: profile.jpg
   ⚠️ PENTING: Huruf kecil semua, pakai .jpg
6. Simpan ke Desktop (sementara)

═══════════════════════════════════════════════════════════════

📂 LANGKAH 2: COPY KE FOLDER PROJECT

LOKASI TUJUAN:
D:\Personal Branding\noe-portfolio\public\images\

CARA COPY:

Opsi A - File Explorer (Paling Mudah):
1. Buka File Explorer (Windows + E)
2. Navigate ke: D:\Personal Branding\noe-portfolio\public\images\
3. Buka folder Desktop di window lain
4. Copy file profile.jpg dari Desktop
5. Paste ke folder images

Opsi B - Drag & Drop di VS Code:
1. Buka VS Code
2. Di sidebar kiri, klik folder "noe-portfolio"
3. Expand: public → images
4. Drag file profile.jpg dari Desktop
5. Drop ke folder images di VS Code

❓ TROUBLESHOOTING

Problem: Foto tidak muncul di website

Solution 1 - Check nama file:
   cd noe-portfolio/public/images
   dir
   → Harus muncul: profile.jpg

Solution 2 - Check browser console:
   Tekan F12 di browser
   Lihat tab Console
   Cari error 404

Solution 3 - Clear cache:
   Tekan: Ctrl + Shift + R

Solution 4 - Restart server:
   Ctrl + C (stop)
   npm run dev (start lagi)
